# 乐愈伴 - 中老年AI音乐疗愈助手
面向50-75岁中老年群体的适老化AI音乐疗愈Web Demo，覆盖情绪舒缓、睡眠改善、精神陪伴三大核心场景，通过AI编程工具快速落地的可交互产品原型。

## 📌 项目背景与定位
当前中老年群体精神陪伴与情绪健康需求缺口显著，慢性病伴随的焦虑、失眠问题普遍，而传统音乐疗愈存在门槛高、适配性不足、操作复杂等痛点。
本项目以「专业音乐疗愈+适老化AI交互」为核心差异化方向，打造轻量化、零学习成本的数字健康工具，帮助中老年用户通过音乐舒缓情绪、改善睡眠。

## ✨ 核心功能
1. **个性化音乐疗愈处方**
   基于情绪自评、睡眠状态、健康基础信息，匹配对应节奏、曲风的疗愈音乐方案，覆盖助眠、舒缓焦虑、情绪提振三大场景。

2. **全语音交互引导**
   支持全程语音操控与语音播报，配套口语化步骤引导，大幅降低中老年用户使用门槛。

3. **情绪追踪与效果反馈**
   记录每日情绪状态与使用时长，生成周度变化报告，以大字、极简图表呈现疗愈效果与健康建议。

4. **轻量AI陪伴互动**
   内置AI语音陪伴对话，支持日常闲聊、怀旧话题引导、健康提醒，填补精神陪伴空缺。

## 🛠️ 构建方式与工具栈
- **产品设计**：独立完成用户研究、需求拆解、原型设计、全流程适老化交互规范定义
- **原型落地**：借助AI编程工具快速生成前端交互代码，完成可交互Demo开发与可用性测试
- **技术实现**：纯前端 HTML + CSS + JavaScript 实现，无需后端服务，开箱即可运行
